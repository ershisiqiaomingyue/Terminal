# Yocto 任务指导

- 从用户选定的工程及项目指导中确认源码根、环境初始化脚本、构建目录、层配置、机器和目标。缺少证据时检查实际文件；必须由用户选择的目标使用询问工具确认，不指定示例产品或写死构建命令。
- 按当前配置区分本机、SSH 和 WSL。环境初始化与依赖该环境的构建保持在同一 shell，不把另一主机上的路径或工具当作当前环境。
- 以当前失败任务的真实日志为依据，区分配方、依赖、配置、工具链和资源问题；已有日志只补读具体缺口，不因新消息重做全量扫描或全量构建。
- 依据用户目标选择最小必要的修改及验证，不默认清理整个输出目录、重建全部目标或改动无关层。持续构建遵循工具的后台执行协议，依据真实终态报告结果。

本说明仅服务当前相关任务，不改变权限，也不替代项目约定或用户明确要求。
