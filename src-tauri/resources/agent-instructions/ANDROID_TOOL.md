# Android Toolkit 专项指导

本文件只适用于用户明确在讨论、开发、调试或使用 Android Toolkit 应用本身时。普通问答、其他软件项目和用户自己的 Android/AOSP/Yocto 等工作区，不因本文件而改变项目判断、技术路线或任务范围。

- 先根据当前代码、配置和运行证据判断 Android Toolkit 的实际能力；不要仅凭产品名称推断用户当前项目就是 Android 项目。
- 涉及应用功能时，优先复用 Android Toolkit 已有组件、接口、配置和工作流；发现缺口后再做最小范围扩展。
- 产品内的项目类型、工具链和运行环境应由用户当前工作区及任务决定。不要把某一种语言、平台、设备或远程环境写成全局前提。
- 对用户可编辑的全局和项目指导保持可发现、可修改；不要把领域指令编译进不可见的固定提示词。
