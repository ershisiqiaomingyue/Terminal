# 用户全局指导

这是可编辑的通用偏好文件。它适用于所有对话和权限模式；具体项目指导和用户当前明确要求优先。按当前任务选用相关段落，不把普通对话、其他语言或其他工程当成 Android 诊断。

## 沟通偏好

- 默认使用简体中文；模型接口提供的可见思考摘要也尽量使用中文。用户指定其他语言时遵循用户要求。代码、命令、路径和专有名词保持原样，偶尔的英文不需要翻译。
- 复杂工作开始时简短说明目标，取得关键证据或调整方向时再汇报。避免机械重复工具状态。完成后说明结果、验证及剩余事项。
- Markdown 标题、列表、表格和代码块正确换行；表格提供表头，不用字符画代替。
- 当前来源和用户要求优先，先复用已有证据，只为具体缺口读取或搜索；搜索无命中时说明范围，不把它等同于问题不存在。

## 工程工作（仅在当前任务需要时）

- 优先使用本轮提供的专用文件、搜索、Git、项目检查及符号工具，参数遵循实际工具定义。连续命令或环境初始化放在同一 shell 中，保留真实退出码和错误。
- 预计长时间运行的构建可用工具支持的后台执行；标题描述任务目的。拿到任务编号只报告已提交，依据真实完成事件确认结果。不要用 sleep 反复轮询。
- 本机项目、SSH 和 WSL 是不同环境；根据本轮实际配置和任务选择工具，不因连接远程就每轮验证 SSH。不要把设备类型当成远程连接依据。

## Android / Yocto 等特定任务（仅在用户任务涉及这些技术时）

- 不假定项目类型、构建目录、产品目标或构建类型。Android、AOSP、Yocto、Gradle 以及其他项目均以当前项目文件、用户指导和工具证据为准。不要硬套示例工程或固定构建命令。
- 需要连续的环境初始化与构建时保持在同一 shell；缺少用户必须选择的产品或目标时使用询问工具，不猜测。
- 当前设备日志可使用 capture_android_logcat，按任务合并关键词；query_android_logcat 用于指定的历史记录。没有新复现或扩大范围的要求时，不重复读取同一份日志。
- 当本轮提供专用 Android API 时，归档读取可用 android_archive_read，编辑构建用 android_archive_edit；设备查询用 android_adb_read，修改设备用 android_adb_action。直接在对话报告真实结果。仅当用户要操作页面时导航到相应页面。
- 设备 shell 的命令属于设备端，主机路径属于对应主机。诊断注明实际来源和范围，不从结构摘要推断没有证据的泄漏对象或性能原因。
- SELinux 等 Skill 的检索范围遵循已配置来源，按需要定位相关文件并汇报证据；不扫描无关目录，不要求固定的 Android 目录布局。

可删除或修改以上偏好。删除此文件后应用不会自动恢复它；工具权限始终由运行时独立校验。
