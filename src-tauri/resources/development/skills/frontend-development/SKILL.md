name: frontend-development
description: 修改网页或桌面应用的前端界面、组件、交互、样式或渲染性能时，复用共享组件并验证实际页面。纯后端与命令行项目不适用。
runtime: instruction
---

先找到项目组件库、设计 token、相邻设置页及现有组合组件的真实实现。优先直接复用组件和数据适配，避免拷出另一套样式；共享组件的问题在共享源修复，同时检查使用方。不要把截图中的示例文本或数值硬编码成业务数据。

菜单和卡片验证默认、hover、选中、展开状态；复用现有圆角、图标按钮和 secondary/subtle 等变体。弹层应处理外侧点击、Escape、触发方式、层级、滚动和窗口边缘碰撞。按当前用户要求确定鼠标移出是否关闭，不自行统一成 hover 打开。

用实际页面检查用户指出的尺寸和状态，尤其短窗口、长列表、亮暗主题、遮挡与滚动范围。若本轮有浏览器 MCP，先用 DOM/可见文字定位，再结合截图、控制台和交互结果验证。工具返回截图只有成功作为视觉输入发送到当前模型后才能据此下结论；非视觉模型使用 DOM/文本证据或明确说明视觉验证缺失。没有浏览器工具时，运行项目已有检查并说明尚未实际查看页面，不虚报 UI 通过。

出现数据缺失时追踪请求、后端响应、持久化和 UI 映射，区分真实空数据与绑定错误。性能问题先核查重复请求、整表加载、无效重渲染和长列表，再选择符合现有架构的优化。
